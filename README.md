# Advance-Imposter
Upgraded the "imposter" game on playstore, needed to update it because it had only few collection of words in each category, so I added Gemini' API to generate a new word every time a room is created. 

An enhanced mobile party deduction game built using Flutter and Dart. Designed for offline group gatherings with friends, featuring dynamic category selection, hidden imposter roles, custom game mechanics, and automated turn rotation.
- Dynamic Category Matrix:** Choose from multiple categories like Food, Movies, Animals, Gaming, and more.
- Custom Player Lobbies:** Support for flexible player counts and custom friend names.
- Secret Role & Hint Engine:** Automatically assigns secret keywords to innocent players and clever category hints to imposters.
- Timed Security Reveal:** Pass-the-device secure peek screen with an active countdown timer to prevent cheating.
- Discussion Board:** Built-in rulebook with randomized starting speakers and rotation flow (Clockwise, Counter-Clockwise, or Chaos).
🛠️ Built With
- Framework:** Flutter
- Language:** Dart
